## 一、原理

### 核心架构

```
┌─────────────┐      串口       ┌──────────────┐
│  上位机     │ ==================> │  ESP32 设备  │
│  (Python)   │  JSON 命令          │  (AI-SDK)    │
│             │ <================= │  调用云端API  │
│  查看结果   │      测试结果         │              │
└─────────────┘                   └──────────────┘
```

### 工作流程

1. **上位机**：读取 Excel 测试集 → 转换为 JSON → 串口发送
2. **ESP32**：接收 JSON → 解析命令 → 调用 AI-SDK → 返回结果
3. **上位机**：接收串口输出 → 显示测试结果

## 二、环境搭建

### 2.1 硬件准备

| 设备 | 说明 |
|------|------|
| **ESP32 开发板** | ESP32-S3 / ESP32-BOX3 / 其他 ESP32 系列 |
| **USB 数据线** | 支持 UART 通信（4 线：VCC、GND、TX、RX）|
| **PC** | Windows / Linux / macOS |

### 连接方式

```
ESP32 设备
    ↓
USB-UART (FT232/CP2102)
    ↓
PC USB 端口
    ↓
识别为 COM 端口 (如 COM3)
```

### 2.2 软件准备

#### 固件端（ESP32）

**要求**：
- ESP-IDF 5.4.3+
- 启用 C++ 异常：`CONFIG_COMPILER_CXX_EXCEPTIONS=y`
- 启用 C++ RTTI：`CONFIG_COMPILER_CXX_RTTI=y`

**编译命令**：
```bash
cd E:\github\ESP32-RTOS-AI-SDK
idf.py build flash monitor
```

#### 上位机（PC）

**安装 Python 依赖**：
```bash
pip install pandas pyserial
```

## 六、固件代码关键点

### 6.1 串口配置

```cpp
uart_config_t uart_config = {
    .baud_rate = 115200,
    .data_bits = UART_DATA_8_BITS,
    .parity = UART_PARITY_DISABLE,
    .stop_bits = UART_STOP_BITS_1,
};
uart_param_config(UART_NUM_1, &uart_config);
```

### 6.2 接收 JSON 命令

```cpp
// 读取串口数据
int len = uart_read_bytes(UART_NUM_1, data, sizeof(data), 100);

// 解析 JSON（简化示例）
if (buffer.find("\"type\":\"chatbot\"") != std::string::npos) {
    // 提取 input 并执行测试
    run_chatbot_test(question);
}
```

### 6.3 调用 AI-SDK

```cpp
auto& aiKit = AIAssistantManager::getInstance().aiFoundationKit();

ChatbotCompletionRequest req;
req.messages = {{"user", question}};
req.stream = false;

aiKit.largeModelChatbot(req,
    [&](const ChatbotCompletionResponse& resp) {
        // 处理返回结果
        ESP_LOGI(TAG, "[PASS] 返回成功");
    },
    [&](const std::string& error) {
        ESP_LOGE(TAG, "[FAIL] 错误: %s", error.c_str());
    }
);
```

## 七、故障排查

### 问题 1：串口无响应

| 检查项 | 解决方法 |
|--------|----------|
| 串口号错误 | 检查设备管理器，确认 COM 口 |
| 波特率不匹配 | 确认双方都是 115200 |
| 固件未启动 | 检查 monitor 输出 |

### 问题 2：命令无响应

| 检查项 | 解决方法 |
|--------|----------|
| JSON 格式错误 | 确认 JSON 有效，以 \n 结尾 |
| 引号转义问题 | 使用 \" 而非 " |
| 缓冲区满 | 等待设备处理完成 |

### 问题 3：API 调用失败

| 检查项 | 解决方法 |
|--------|----------|
| WiFi 未连接 | 检查网络连接 |
| Token 无效 | 检查配置文件 |
| 网络超时 | 增加超时时间 |
