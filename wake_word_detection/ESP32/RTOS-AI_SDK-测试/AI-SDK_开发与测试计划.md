# AI-SDK 开发与测试计划

## 文档信息

- **项目名称**: ESP32 RTOS AI-SDK 测试框架开发
- **创建日期**: 2026-02-02
- **版本**: v1.0
- **项目类型**: 新功能开发 + 测试验证

---

## 一、项目概述

### 1.1 项目背景

当前 ESP32-RTOS-AI-SDK 项目需要建立一套完整的测试框架，用于验证 AI-SDK 的 4 大 AI 能力（ASR 智能对话、大模型闲聊、文本翻译、内容摘要）是否能正常返回结果。

### 1.2 项目目标

- **主要目标**: 搭建串口输入 + 固件测试框架
- **测试目标**: 验证 AI-SDK 各项 AI 能力的功能可用性
- **交付物**: 可执行的测试固件 + Python 测试脚本 + 测试文档

### 1.3 现有资源

| 资源类型 | 位置/说明 |
|----------|-----------|
| **测试数据** | `RTOS-AI_SDK-测试/测试集/` 下的 4 个 Excel 文件 |
| **AI-SDK 源码** | `components/ai_sdk/` 静态库 + 头文件 |
| **主程序** | `main/` 应用程序 |
| **构建系统** | ESP-IDF 5.4.3+ |

### 4.2 上位机脚本任务清单

#### 任务 1: Excel 读取模块（优先级：P0）

**文件**: `scripts/excel_reader.py`

**功能要求**:
- [ ] 读取 `大模型问答测试集.xlsx`
- [ ] 读取 `12月11号测试用例.xlsx`
- [ ] 处理编码问题（UTF-8）
- [ ] 数据清洗（去空、去重）
- [ ] 输出标准格式数据结构

**输出格式**:
```python
{
    "chatbot_tests": ["问题1", "问题2", ...],
    "translate_tests": [
        {"source": "文本1", "target_lang": "zh", ...},
        ...
    ]
}
```

---

#### 任务 2: 串口通信模块（优先级：P0）

**文件**: `scripts/uart_comm.py`

**功能要求**:
- [ ] 串口打开/关闭
- [ ] JSON 命令发送
- [ ] 串口数据接收（非阻塞）
- [ ] 编码转换（UTF-8）
- [ ] 错误处理（串口断开、超时）

**接口设计**:
```python
class UARTCommunicator:
    def __init__(port, baudrate)
    def send_command(self, cmd_dict)  # 发送 JSON 命令
    def receive_data(self, timeout=1)  # 接收数据
    def close(self)  # 关闭串口
```

---

#### 任务 3: 测试执行器（优先级：P0）

**文件**: `scripts/run_ai_sdk_tests.py`

**功能要求**:
- [ ] 加载 Excel 测试数据
- [ ] 遍历测试集，生成 JSON 命令
- [ ] 通过串口发送命令
- [ ] 接收并解析测试结果
- [ ] 统计通过/失败数量
- [ ] 生成测试报告

**执行流程**:
```
1. 读取 Excel 测试集
2. 生成 JSON 命令
3. 串口发送命令
4. 等待设备响应
5. 记录测试结果
6. 生成测试报告
```
